# Product Steering

## Product Overview

**cfg** は Go 言語製の設定管理ツール＆ライブラリです。アプリケーションの設定値を YAML ファイルで定義し、AWS Parameter Store と環境変数を統合的に管理することで、環境（local/dev/stg/prod）ごとの設定値を透過的に使い分けできます。

実運用では Parameter Store への設定値登録・管理を支援する CLI ツール（cfgctl）も提供します。

## Core Features

### ライブラリ機能（cfg パッケージ）

- **動的値解決**: `${ps:/path}` と `${env:VAR}` 記法による YAML 内での値の動的取得
- **Stage 管理**: `{stage}` プレースホルダーによる環境別設定の自動切り替え
- **文字列補間**: 値だけでなく文字列内での `${env:NAME}-{stage}` のような複合参照
- **型安全な読み込み**: Go 構造体タグベースの型安全な設定値マッピング
- **AWS 統合**: IAM ロール・環境変数による自動認証
- **バッチ最適化**: AWS API の効率的な呼び出し（10 パラメータ単位でのバッチ処理）
- **パス prefix 管理**: 名前空間管理による設定値の一元化

### CLI ツール機能（cfgctl）

- **Parameter Store 操作**: 値の設定・取得・削除・一覧表示
- **セキュア入力**: 機密値（SecureString）の対話式非表示入力
- **マルチステージ比較**: dev/stg/prod 間での設定値の差分確認
- **KMS 統合**: リージョン・ステージ別の KMS 暗号化鍵管理
- **パスプレフィックス対応**: 相対パス設定による設定値の効率的な管理
- **設定ファイル管理**: ~/.cfgctl.config での CLI デフォルト設定

## Target Use Case

このツール・ライブラリは以下のユースケースに対応します：

1. **マルチ環境アプリケーション**: 開発環境（local/dev）から本番環境（prod）まで、同じコードベースで異なる設定を使用
2. **秘密値の集中管理**: データベースパスワード、API キー、トークンなどを Parameter Store で一元管理
3. **設定変更の運用効率化**: アプリケーション再デプロイなしに Parameter Store での設定変更が即座に反映
4. **チーム開発での設定共有**: YAML ファイルはリポジトリに含め、秘密値は Parameter Store で分離管理
5. **監査・コンプライアンス**: Parameter Store の change log による設定変更の追跡と承認ワークフロー対応

## Key Value Proposition

- **シームレスな統合**: YAML ベースの設定と Parameter Store を同じ記法で扱える
- **環境別の透過的切り替え**: Stage 管理で環境ごとの設定値の自動解決
- **セキュリティと利便性の両立**: 秘密値は暗号化・集中管理しながら、開発での効率性を損なわない
- **運用効率**: パスプレフィックスやマルチステージ比較により、設定管理の負担を大幅削減
- **AWS ネイティブ**: IAM による権限管理で、追加の認証機構が不要
